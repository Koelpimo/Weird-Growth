Weird Growth ist ein System, das Differential Growth darstellt — ein Wachstumsmodell, das an verschiedenen Orten in der Biologie vorzufinden ist, wie zum Beispiel beim Wachstum von Pflanzen.

Das Wachstum beginnt mit einer geschlossenen Kontur oder Linie. Darauf sind Nodes platziert, die sich abstoßen, wenn sie zu nah aneinander liegen — wodurch sich die Form ausdehnt. Sobald die Nodes zu weit auseinander sind, entsteht eine neue Node zwischen diesen. So wächst eine Struktur, die sich langsam ausdehnt, und ein organisches System entsteht.

parameter

  • Liniendicke Stärke der Linien in Pixeln.
  • Kraft Anziehung: Nodes rücken zusammen · Abstoßung: Nodes weichen aus.
  • Komplexität Feinheit der Start-Kontur (~10 grob, ~100 fein).
  • Neue Node Abstand für Kantenteilung (2–16 px); kleiner = dichter, größer = grober.
  • Limit Max. Nodes (2000–12000); Schutz vor Überlastung.
  • Verbindungen 3D Verbindungsreichweite im Raum.
